# KTX 히어로 (인트로 모션)

`index.html`을 더블클릭하면 브라우저에서 열려요. 인터넷과 로컬 서버가 없어도 돼요.

## 디자인 (2026-11-06, 무드보드 "맑은 하늘")
- 맑은 한낮의 하늘 위에 장면이 떠 있어요. 하늘색은 무드보드 원본 사진에서 뽑았어요.
- 흰 콘크리트, 광택 도장, 하늘이 비치는 유리, 강철 레일처럼 소재별로 빛을 받아요. 강한 직사광이 푸른 그림자를 만들어요.
- 화면 전체에 아주 옅은 필름 그레인이 깔려요. 움직이지 않는 고정 입자이고, 필름 필터 안에서 그려요(`scene-spec.js`의 `film.grain`).
- 빛, 그림자, 안개 값은 `scene-spec.js`의 `look`, 색은 `colors`에 있어요.
- 이전 글자(ASCII) 버전은 정리하며 지웠어요. 필요하면 git 기록(커밋 05b5c63 이전)에서 꺼내요.
- KTX, 비행기, 역, 공항은 `models/models.js`의 실사풍 모델과 표면 재질을 써요. 모델 미리보기 페이지와 GLB 파일은 정리하며 지웠어요(git 기록에 있음).
- 필름 필터(cosmos.so/e/1108859166 참고): 필름 입자, 부드러운 초점, 밝은 물체 가장자리의 붉은 번짐, 분홍빛 하이라이트, 남청 그림자, 분홍빛 구름. 값은 `scene-spec.js`의 `film`. 메뉴와 버튼에는 적용하지 않아요.

## 시간대 (2026-11-13)
방문자 기기의 현재 시각에 맞춰 하늘, 햇빛, 조명이 바뀌어요. 해외 장면도 같은 현지 시각을 써요.

| 단계 | 언제 | 화면 |
|---|---|---|
| 새벽 | 해 뜨기 70분 전부터 해 뜬 직후까지 | 남보라 하늘, 복숭아빛 지평선, 낮게 비치는 따뜻한 빛 |
| 낮 | 그 이후부터 해 지기 80분 전까지 | 맑은 한낮 (기본 디자인) |
| 노을 | 해 지기 직전 | 주황빛 지평선, 낮은 오렌지 햇빛 |
| 블루 아워 | 해 진 뒤 약 25분 | 짙은 파랑, 조명이 켜지기 시작 |
| 밤 | 해 진 뒤 70분부터 다음 새벽까지 | 남색 하늘과 별, 달빛, 하늘색 조명, 다홍 포인트 |

- 해 뜨고 지는 시각은 날짜로 계산해서 계절이 반영돼요 (서울 위도 기준).
- 단계 사이는 부드럽게 섞이고, 1분에 한 번만 시각을 다시 확인해요.
- 밤에는 가로등, 캐노피와 터미널 조명, 건물 창이 하늘색으로 켜지고, 활주로 등과 승강장 가장자리 띠만 다홍색이에요. 전광판은 역 전체 화면에서도 켜져 있어요.
- 값은 `scene-spec.js`의 `timeOfDay`에 있어요 (단계별 하늘색, 해와 달, 반사광, 필름 색감, 조명 세기, 밤 조명색).

## 장면 순서 (약 7초, 처음 버전의 순서)
1. 0.1초부터: 승강장 판이 앞쪽부터 물결처럼 땅에서 솟아요.
2. 이어서 건물, 기둥과 지붕, 게시판이 차례로 솟아 완성돼요.
3. 1.4초부터: 도상, 침목, 레일이 차례로 솟아요 (공항은 활주로).
4. 3.4-6.8초: KTX가 오른쪽 위에서 들어와 정차해요 (공항은 비행기가 내려앉아 들어와요).
5. 정차 후에는 마우스를 따라 장면이 아주 살짝 돌아요.

## 인터랙션
- 오른쪽 아래 작은 블러 원(?)을 누르거나 `?` 키를 누르면 화면 전체에 강한 블러가 깔리고 설명이 떠요(`help.js`, `help.css`). 화면 버튼을 누르면 그 화면 설명과 가는 법이 나오고, 열 때는 지금 보고 있는 화면부터 보여 줘요. `Esc`, X, 빈 곳을 누르면 닫혀요. 열려 있는 동안 `Esc`는 설명만 닫아요. 설명 창의 낮·노을·밤 토글로 장면 시간대를 바로 바꿔요(1.2초 동안 부드럽게 넘어가고, 새로고침하면 실제 시각으로 돌아가요).
- 정차 후 역을 누르면 승강장 시점으로, 공항은 터미널 안으로 이동해요. `Esc`나 버튼으로 돌아가요.
- KTX나 비행기를 누르면 객실 좌석에 앉은 눈높이로 들어가요 (아래 "좌석 시점"). 공항 터미널 시점에서는 탑승구(문, 위 표지, 탑승교)를 눌러도 좌석으로 가요.
- 오른쪽 위 다이얼에서 `국내`/`해외`를 누르거나 가운데 손잡이를 누르면 지금 장면이 처음 순서의 반대로 빠르게 거둬지고(약 1.4초), 새 장면이 처음 순서대로 지어져요. 하늘은 해외일 때 조금 더 깊은 파랑이 돼요.
- 움직임 줄이기 설정을 켜 두면 마지막 장면만 보여줘요.

## 좌석 시점 (2026-11-18)
KTX나 비행기를 누르면 내 좌석에 앉은 시점이 돼요. 왼쪽 아래에는 종이 지도, 오른쪽 아래에는 휴대폰을 손에 든 것처럼 화면의 절반쯤씩 채워요.

- **전체 화면에서 누르면** 승강장·터미널 시점을 거치지 않고 곧바로 들어가요. 먼저 줌이 들어가며 내 좌석 창문 정면까지 내려앉고(창문이 화면을 채우며 잠깐 머묾), 겉면이 녹으면서 창 한가운데를 지나 들어가 진행 방향으로 고개를 돌려 앉아요. `Esc`나 `역 전체 보기`(`공항 전체 보기`)를 누르면 같은 길로 전체 화면에 돌아가요.
- **승강장·터미널 시점에서 누르면** 그 자리에서 좌석으로 옮겨 앉아요. `Esc`나 `승강장 보기`(`게이트 보기`)는 시점으로, 한 번 더 누르면 전체 화면으로 돌아가요.
- 종이 지도: 국내는 한반도 위 KTX 노선(경부·호남·전라·강릉)과 이번 시즌 축제, 해외는 세계지도 위 인천 출발 항로예요. 누르면 들려 올라와 입체 지도가 돼요 (아래 "입체 지도").
- 휴대폰: 동반자 앱 홈과 같은 화면이에요. 누르면 들려 올라와 동반자 앱이 열려요 (아래 "동반자 앱").
- 지도와 휴대폰 내용(일정, 동반자, 축제, 금액)은 지금은 예시예요.
- 값은 `scene-spec.js`의 `seat`에 있어요: `dur`(시점에서 좌석까지), `direct`(직행 시간, 창 앞 거리와 화각, 겉면이 녹는 구간), `held`(지도와 휴대폰의 위치와 크기, 세로 화면용 `narrow`), 장면별 `eye`/`look`/`fov`(앉은 눈), `gate`(직행 때 지나는 창).

## 입체 지도 (2026-11-21, 해외 2026-11-22)
좌석에서 종이 지도를 누르면 지도가 들려 올라와 화면을 채우고, 종이색 덮개 아래에서 입체 지도로 바뀌어요.

- **국내**: 실제 고도로 만든 한반도 부조. 지역을 누르면 그 지역으로 다가가고, 장소 점과 이름이 보여요. 장소를 고르면 설명 카드가 지도 위 그 장소 옆에 붙고(카메라가 움직여도 따라감), 왼쪽 추천 목록은 고른 줄만 강조해요. 빈 종이를 누르면 카드가 닫혀요.
- **해외**: 같은 엔진으로 그린 세계 지도에서 시작해요. 일본(또는 일본 장소)을 누르면 일본으로 다가간 뒤 일본 지도로 넘어가고, 일본 전체에서 뒤로 가면 세계 지도로 돌아와요. 지금은 일본만 코스를 만들 수 있어서 다른 지역은 "곧 열려요" 안내만 떠요. 세계 지도에서 담은 장소는 일본 지도로 그대로 이어져요.
- 해외 지도 데이터(약 4.6MB)는 해외를 처음 열 때 받아요. 0.3초 넘게 걸리면 덮개 위에 진행 막대가 뜨고, 받지 못하면 안내 뒤 좌석으로 돌아가요. 해외 모드로 바꾸는 순간 미리 받기 시작해요.
- 재질, 빛, 등고선, 밤 색은 국내와 같아요. 해외는 건물 없이 지형만 그려요.

## 코스 만들기와 내 코스
입체 지도 왼쪽 위의 `탐색 / 내 코스`로 오가요. 국내와 해외는 화면 짜임이 같고 데이터만 달라요 (`course-data.js`, `course-data-jp.js`).

- **탐색**: 장소를 담을 때마다 아래 코스 바에 번호가 쌓여요. `코스 편집`으로 새 코스가 돼요.
- **내 코스**: 다가오는 여행, 만드는 중, 다녀온 여행. 카드를 누르면 그 자리에서 일차별 일정이 펼쳐지고, 안의 `코스 편집`으로 들어가요. 축제 시간이나 비행편이 바뀌면 카드에 알림이 떠요.
- **코스 편집**: 일차별 도시 카드(끌어서 순서 바꾸기), 이동 칩(국내 KTX, 해외 비행·JR·렌터카), 숙소 줄, 오른쪽 `출발 전 확인`(나와 동반자별 남은 준비).
- **세부 코스**: 부산과 삿포로는 OpenStreetMap으로 그린 평면 지도 위에서 짜요. 끌어서 이동, 휠로 확대. 장소를 누르면 사진과 운영 정보가 담긴 카드가 그 장소 옆에 붙어요. `지도에서 장소 추가`의 검색 결과도 카드부터 열려요. 다른 도시는 입체 지도로 보여 줘요.
- **AI 코스**: 한 문장 요청 → 만드는 중(단계와 지도가 차례로 채워짐) → 제안 3개 → 도시별 AI 세부 코스.

## 동반자 앱 (2026-11-22)
좌석의 휴대폰이나 코스 화면의 사람 얼굴, 코스 편집 위 `동반자` 줄, `동행에게 공유`를 누르면 그 자리의 휴대폰이 들려 올라와 앱이 열려요. 바깥을 누르거나 `Esc`로 내려놓아요. 흰색과 브랜드 블루(#1478D6)만 쓰고, 밤에도 앱 안은 그대로예요.

- **탭**: 동반자(지금 할 일, 함께 가는 사람, 새 소식), 투표(사진 후보, 정해지면 `코스에 넣기`로 코스 편집에 실제로 들어감), 정산(받을 돈·보낼 돈, 쓴 돈 넣기), 합류(만날 곳, 사람별 도착). 머리의 사람 더하기로 초대(링크, 권한).
- **왼쪽 큰 화면**: 고른 탭을 크게 펼쳐 봐요. 다음 순서 카운트다운과 그날 일정, 평면 지도 위 투표 후보, 사람별 낸 돈과 몫 막대, 만날 곳까지 오는 길.
- 앱이 떠 있는 동안 뒤 장면은 멈추고(가벼움), 키보드 `Tab`은 휴대폰 안에서만 돌아요. 닫으면 앱을 연 버튼으로 포커스가 돌아가요.
- 데이터는 `companion-data.js`(국내 가을 남도, 해외 겨울 홋카이도). 데이터가 없는 코스는 코스의 이름과 사람으로 빈 앱을 만들어요.
- 여러 사람이 실제로 함께 쓰려면 서버가 필요해요. 지금은 이 브라우저 안에서만 바뀌고 새로고침하면 처음으로 돌아가요. 초대 QR은 모양만 QR이에요.

## 모바일 (m/, 2026-11-23)
여행 중에 빠르게 바꾸는 앱이에요 (기획 06-3). Figma '모바일 · 여행 중 앱'을 그대로 옮겼어요. 주소는 따로예요: PC 웹은 `index.html`, 모바일은 `m/`, 워치는 `w/`. 휴대폰으로 PC 주소를 열어도 넘어가지 않아요.

- **시작 화면**: 그 시각의 하늘 가운데 로고, 하늘이 접히며 로고가 머리글로 가고 시트가 올라와요 (0.4초 이상 보여 줌, 1.2초가 넘으면 "코스를 불러오는 중"). 움직임 줄이기를 켜면 바로 홈.
- **하늘**: 웹 히어로와 같은 다섯 단계. 노을 뒤 블루 아워와 밤에는 밤 색(시트 #222541, 카드 #0E112A, 강조 루미너스 코랄 #FF6B57)과 별 하늘.
- **오늘**: 여행 전에는 내 코스와 대략 코스 만들기, 여행 중에는 다음 장소와 출발까지 남은 시간, 그날 일정.
- **대략 코스**: 웹 입체 지도를 찍은 그림 위에서 출발과 도착 지역(국내 시·도, 해외 나라)을 고르고, 날짜와 사람을 정해 초안으로 저장. 자세한 일정은 PC에서.
  - 지도는 두 손가락으로 벌리거나(PC는 휠) 오른쪽 위 + - 버튼으로 3.5배까지 키우고, 끌어서 옮겨요. 핀과 이름표는 같은 크기로 남아요. 지도 그림은 3배 해상도(1860x2100)로 다시 찍었어요.
  - 출발·도착 칸을 누르면 아래에서 지역 고르기 창이 올라와요(묶음별 목록). 출발을 고르면 이어서 도착 창이 열려요.
  - '최근 선택한 곳': 날짜와 사람 고르기로 넘어갈 때 고른 경로와 내 코스 초안의 경로를 보여 줘요(새로고침하면 초안 경로만 남음). '요즘 많이 가는 곳' 위에 있어요.
- **코스**: 길게 눌러 순서 바꾸기, 옆으로 밀어 건너뛰기·바꾸기. 시각, 이동 시간, 1인 예상 비용을 바로 다시 계산.
- **계획이 깨질 때**: 비 알림에서 대체 장소 두 곳과 남은 시간 투표.
- **동행 채팅**: 말풍선 사이에 코스 카드(순서 바꾸기 제안, 지출, 장소, 투표)가 섞여요. 위에 "찬성을 기다려요" 고정 줄, 아래에 빠른 답장(좋아요, 10분 늦어요, 먼저 가 있을게요)과 `+` 빠른 동작(장소 보내기, 투표 만들기, 지출 나누기, 내 도착 예정). `다른 의견`은 그 제안을 인용한 답글. 다른 사람의 답은 '입력 중' 뒤에 오는 미리 정해 둔 연출이에요(m/data.js의 replies).
- **지출**: 금액, 쓴 곳, 낸 사람만 넣어 기록. 기록하면 동행 채팅에도 카드로 올라가요.
- 아무것도 저장하지 않아요. 코스 순서, 초안, 지출, 채팅, 최근 선택한 곳 모두 새로고침하면 처음 상태로 돌아가요. 여러 사람이 함께 쓰려면 서버가 필요해요.
- 확인용: `m/?trip=1`(여행 중), `&time=21:30`(밤), `&rain=1`(계획이 깨질 때), `&tab=course|crew|money`, `&flow=1`(대략 코스), `&flow=2`(날짜와 사람), `&nodemo`(동행 탭을 열 때 나오는 첫 답장 연출 끄기).
- PC처럼 넓은 화면(1000px 이상)에서는 앱 오른쪽에 설명 칸이 붙어요(`m/panel.js`). 버튼을 누르면 그 화면 설명만 바뀌고 앱 화면은 그대로예요. 앱 안에서 탭이나 화면을 옮기면 설명이 따라가요. 휴대폰에서는 보이지 않아요.
- 그림: `m/assets/`의 지도는 웹 입체 지도를 찍은 것, 구름과 밤하늘은 코드로 만든 질감. 아이콘은 Phosphor Icons(MIT).

## 워치 (w/, 2026-11-24)
걷는 중에 지도로 바로 찾는 화면이에요 (기획 06-3). Figma '워치 · 걷는 중 지도'를 애플 워치 46mm(208x248pt) 크기로 옮기고, CSS로 그린 실버 알루미늄 워치에 끼워 보여 줘요. 실제 워치 앱이 아니라 웹 시안이에요.

## 확인용
- `R` 키: 처음부터 다시 재생
- `?t=2.3`: 해당 시점에서 멈춘 화면
- `?q=2`: 품질 단계 고정 (0 = 기본, 3 = 가장 가벼움). 평소에는 기기가 버거우면 자동으로 내려가요.
- `?mode=overseas`: 해외로 시작, `?t=14&pov=1`: 승강장(터미널) 시점 미리보기
- `?time=21:30`: 해당 시각의 하늘과 조명으로 보기 (예: `?t=14&time=05:50`은 새벽)
- `?t=14&pov=1&seat=1`: 좌석 시점, `?t=14&dive=0.7`: 전체 화면에서 좌석으로 가는 직행 전환의 중간 장면 (0에서 1)
- `?t=14&pov=1&seat=1&atlas=1`: 좌석에서 바로 입체 지도 (해외는 `&mode=overseas`로 세계 지도, `atlas=japan`이면 일본 지도)
- `?t=14&course=mine`: 코스 화면으로 바로 (`mine`, `empty`, `edit`, `alert`, `city`, `add`, `ai-start`, `ai-gen`, `ai`, `ai-city`). 해외는 `&mode=overseas`
- `&debug`: 콘솔에서 `window.__atlas`(지금 지도), `window.__phoneRect()`(좌석 휴대폰 화면 위 자리), `window.__companion`(동반자 앱)을 쓸 수 있어요

## 파일 구성
- `scene-spec.js`: 색, 배치, 카메라, 모션 타이밍, 시간대. **Figma와 공유하는 값은 전부 여기에 있어요.**
- `scene.js`: three.js 장면, 타임라인, 시간대 적용, 객실과 좌석 시점
- `posters.js`: 전광판 광고 포스터
- `props.js`: 좌석에서 손에 든 종이 지도와 휴대폰 화면 (휴대폰은 동반자 앱 홈과 같은 모습)
- `atlas.js`: 입체 지도 엔진 (국내, 세계, 일본을 같은 엔진으로). `heightdata.js`(국내 고도)
- `world-*.js`, `japan-*.js`: 해외 지도 데이터와 설정 (처음 해외를 열 때 받음)
- `course.js`, `course.css`: 코스 만들기와 내 코스 화면. `course-data.js`(국내), `course-data-jp.js`(해외)
- `companion.js`, `companion.css`, `companion-data.js`: 동반자 앱
- `assets/course/`: 평면 지도, 장소 사진, 사진 출처 기록(`CREDITS.md`, 화면에는 표시하지 않음)
- `mapdata.js`: 한반도와 세계 윤곽, 국내 지역 (Natural Earth 공개 데이터를 단순화)
- `style.css`: 하늘 배경(시간대에 따라 색이 바뀜), 메뉴(로고와 국내/해외 다이얼), 시점 버튼 스타일
- `fonts.css`: SUIT 폰트(바탕화면 SUIT 폰트 폴더에서 가져와 내장)
- `vendor/three.min.js`: three.js r149

## Figma와 동기화
기준 화면은 **1920 x 1080**이에요. Figma 프레임과 브라우저 1920 화면의 구도가 같아요.

Figma 파일 `ux-ui` > `여행 - 디자인` 페이지
- `KTX 히어로 v4 / ASCII 최종 (정차) 1920`, `Storyboard v4`: 현재 표현. 글자 약 2만 개라 장면은 HTML 캡처 이미지이고, 메뉴만 편집 가능한 레이어예요.
- `KTX 히어로 / 최종 (정차) 1920`: 면으로 그린 벡터 장면 (1920 x 1080). 배치를 고칠 때는 이 프레임을 수정해요.
- `Storyboard / 01–04`: 모션 단계별 장면 (960 x 540, 절반 크기)
- `Logo / eodi 시안`: 로고 시안. 적용된 로고는 `logo-eodi.svg`
- `Tokens / KTX 히어로`: 색, 타이포, 모션

규칙
- 색: Tokens 프레임의 `swatch/<이름>`을 바꾸면 `scene-spec.js`의 `colors.<이름>`에 반영해요.
- 배치: 장면 레이어 이름(`far-platform`, `canopy`, `building` 등)이 `scene-spec.js`의 `boxes[].id`와 같아요.
- 메뉴: Nav 레이어의 글자와 간격을 바꾸면 `index.html`과 `style.css`에 반영해요.

Figma에서 직접 수정한 뒤 다음 대화에서 "피그마 수정한 거 HTML에 반영해줘"라고 하면 바뀐 부분을 읽어 HTML에 옮겨요.
